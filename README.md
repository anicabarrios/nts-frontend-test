# Nationwide Transport Services – Frontend Developer Test

This project recreates the "Transport Your Load On The Right Trailer With Us" section
based on the provided Figma design.

## 🛠 Technologies Used
- HTML5
- CSS3 (Grid, Flexbox)
- Responsive layout

## 📐 Design Notes
- Matches the layout, spacing, colors, and typography from Figma
- Responsive for desktop and mobile
- Clean, semantic, and maintainable code

## ▶️ How to Run
Simply open `index.html` in any modern browser.
